Panduan Penghapusan Data Pengguna

SILA menghormati privasi dan kedaulatan data pengguna. Jika Anda ingin menghapus data akun media sosial yang telah terhubung ke aplikasi SILA, ikuti langkah-langkah berikut:

Cara 1: Pemutusan Mandiri via Dashboard

  1. Buka dashboard aplikasi Anda pada menu Post Automation atau Omni CRM.
  2. Pada bagian Akun Tersambung, cari akun yang ingin diputuskan.
  3. Klik tombol ikon Hapus / Putuskan Koneksi.
  4. Seluruh token otorisasi, riwayat sinkronisasi, dan data terkait akan dihapus secara permanen dari server lokal kami seketika.

Cara 2: Pencabutan Melalui Pengaturan Facebook / Google

Untuk Akun Meta (Facebook / Instagram):

Buka Pengaturan Facebook → Pengaturan & Privasi → Aplikasi dan Situs Web → Cari aplikasi SILA Social Hub → Klik Hapus.

Untuk Akun Google (YouTube):

Buka Google Account Permissions → Pilih aplikasi SILA → Klik Hapus Akses.
